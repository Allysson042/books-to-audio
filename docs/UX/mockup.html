Resumo técnico

gerado agora · 22 s

O ELBO (Evidence Lower Bound) é a função-objetivo do VAE: um limite inferior para a log-verossimilhança dos dados. Em vez de maximizar diretamente log p(x), o modelo maximiza uma quantidade que sabemos ser menor ou igual a ela — e que depende de duas parcelas: a qualidade da reconstrução e a proximidade entre a posterior aproximada e o prior. [Cap 4, p.101]

Na prática, o termo de reconstrução puxa o decoder a reproduzir x a partir de z; o termo KL regulariza q(z|x) para perto de N(0, I). O equilíbrio entre os dois é o que evita colapso do latente e mantém o espaço contínuo — a propriedade que permite gerar amostras novas. [Cap 4, p.104]

ELBO = Eq(z|x)[ log p(x|z) ] − DKL( q(z|x) ‖ p(z) )

O sinal negativo no KL é a razão de o VAE ser “variacional”: sem ele, o modelo pode empurrar q para longe do prior e obter reconstruções boas com um latente desconexo. Com ele, cada ponto decodifica para algo plausível. [Cap 4, p.107]

Para o seminário, a leitura útil é: o ELBO não é uma métrica de qualidade absoluta; é o alvo de treino. Comparar valores de ELBO entre arquiteturas diferentes não diz qual gera melhor. [Cap 4, p.112]

Roteiro falado

gerado agora · 18 s

Vamos entender o ELBO sem fórmula decorada. Pensa num detetive que não vê o crime, só as pistas. O VAE faz o caminho inverso: precisa resumir a imagem num código curto e, desse código, reconstruir a imagem. O ELBO é a nota que diz o quão bom esse resumo é — mas é uma nota sempre um pouco pessimista: ela nunca supera a qualidade real. [Cap 4, p.101]

Essa nota tem duas partes. A primeira premia reconstruções fiéis. A segunda cobra organização: o código precisa ficar perto de uma distribuição simples, tipo uma nuvem em volta do zero. Sem essa cobrança, o modelo decora as imagens e o espaço entre os códigos vira buraco — e aí não dá para gerar nada novo. [Cap 4, p.107]

Por isso dizemos que o ELBO é um limite inferior. Maximizar o ELBO é empurrar o limite para cima; quando ele sobe, a verossimilhança real também sobe. É otimização por procuração: em vez de medir o que não conseguimos calcular, medimos algo que sabemos ser conservador. [Cap 4, p.101]

Se você levar uma ideia só para a prova, leve esta: o ELBO troca um cálculo impossível por dois cálculos fáceis — reconstrução e divergência. O preço é o viés; o ganho é conseguir treinar. [Cap 4, p.112]
